# Bunutan Pasko 🎄

A Filipino Christmas monito-monita web app.

## Setup
1. `npm install`
2. Create Supabase project, run `supabase/schema.sql`
3. `cp .env.example .env.local` and fill values
4. Drop your music at `public/audio/pasko.mp3`
5. `npm run dev`

## Stack
Next.js 14 · Supabase · Tailwind · Vercel
